## Why

Live sessions can be scheduled and attended, but there is no capacity-aware booking, waitlist, learner calendar, or calendar-feed integration.

## What Changes

- Add optional booking windows and capacity to live sessions.
- Add cancellation, waitlist promotion, and attendance-aware booking status.
- Add personal calendar views and revocable iCalendar feeds.

## Capabilities

### New Capabilities
- `live-booking-calendar`: live-session reservations, waitlists, and calendar views.

### Modified Capabilities
- None.

## Impact

- Extend the Live module with booking aggregates while preserving unrestricted sessions when booking is disabled.
